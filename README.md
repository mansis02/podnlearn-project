# PodnLearn™ - Podcast Player and AI-based Learner

**Made using ASP.NET**

PodnLearn is a Podcast and AI-based e-book learner web application designed to provide users with access to podcasts and an AI-powered learning feature. Users can explore podcasts, listen to content, and use the LearnAI feature to convert e-book/PDF content into voice-based learning material.

## Key Features

* Podcast streaming and browsing
* User registration and login
* Favourite/subscribed podcast content
* LearnAI feature for e-books/PDFs
* Text-to-speech based learning
* User profile and content management
* SQL Server database integration

## To Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `PodnLearn.sln` using Visual Studio.
4. Configure the required SQL Server LocalDB database.
5. Create the required databases and tables.
6. Run the project using Visual Studio.
7. The PodnLearn web application will open in the browser.

## Project Overview

PodnLearn was developed as an academic project combining podcast streaming with an AI-based learning experience. The platform focuses on making learning more accessible by allowing users to listen to podcasts as well as convert written e-book content into audio.
