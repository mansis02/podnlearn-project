# PodnLearn – AI-Based Podcast & Learning Platform

PodnLearn is a full-stack web application that combines podcast streaming with AI-based e-book to audio conversion to improve digital learning accessibility.

## Features
- Podcast streaming and user-generated content upload  
- PDF to audio conversion using Text-to-Speech (TTS)  
- User authentication and personalized dashboard  
- Audio-based learning for better accessibility  

## Technologies Used
- ASP.NET (C#)  
- SQL Server  
- HTML, CSS, JavaScript, Bootstrap  
- Python (for TTS processing)  

## Key Highlights
- Built a system to convert e-books into audio format  
- Focused on accessibility for visually impaired users  
- Designed a user-friendly interface and backend system
